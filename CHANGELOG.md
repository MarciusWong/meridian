# Changelog

## 1.0.0

First public release.

- Global time-to-first-byte measurements from up to 30 cities on every continent via Globalping, with cold and warm
  requests and ping round-trip times.
- Lighthouse audits on mobile and desktop through PageSpeed Insights (with Chrome UX Report real-user data) or local
  headless Chrome.
- Page inspector for redirects, compression, HTTP/2 and HTTP/3, caching headers, CDN detection, TLS and HTML structure.
- Optional WebPageTest real-browser runs.
- Prioritised recommendations with severity, evidence and fix steps, merged across tools.
- Web UI with world map, timing breakdown, Core Web Vitals, page weight and technical details; light and dark themes.
- Shareable report links, JSON export, print, and Markdown checklist export.
- Public-hosting defaults: SSRF protection, per-client rate limits, strict CSP, private per-browser history, report
  retention, Docker image with Chromium.
